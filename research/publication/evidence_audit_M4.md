## 1. What was checked

1. **Raw-output integrity.** The 219 files listed in `results/raw/{EXP-001,EXP-002,PILOT-QUIET}/SHA256SUMS` were re-hashed: 0 mismatches. The digests of the three `SHA256SUMS` files are recorded in the manifest (`raw_outputs`), because `results/raw/` is excluded from git.
2. **Every displayed number.** Each number in `research/paper/manuscript.md`, `research/paper/supplementary.md`, `research/claims_register.csv` and the four experiment reports is a manifest entry with experiment id, run set, metric definition, result path, locator, generator script, config and protocol hashes and code revision. The script reads the raw value at the locator and requires the displayed text to equal it at the displayed precision.
3. **Coverage.** The script extracts every numeric token of the scanned documents and requires it to be an entry, a listed design parameter (N, payload, skew, seeds, thresholds, resamples, versions) or a structural token (section numbers, years, counts below 100, HTTP status codes, identifiers, paths and hashes in code spans).
4. **Denominators, units, precision, uncertainty, sample counts.** Checked by hand against the raw outputs for every table in the manuscript and supplementary file (section 2).
5. **External claims.** Each citation was matched against `research/literature_review.md` and labelled in the text and in the reference list with its access level (section 4).
6. **Figures.** The four EXP-002 and two EXP-001 figure files are hashed in the manifest; they were generated by `scale analyse` at M3 from the same `analysis.json` files that the manuscript cites, and were not regenerated at M4.
