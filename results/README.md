# results/

Machine-readable experiment outputs. `results/raw/` holds large raw outputs; it is excluded from git (`.gitignore`) and regenerated by the runner. Small summaries and manifests live next to each experiment in `research/experiments/EXP-NNN/`.

Empty at M0: no experiment has run.
